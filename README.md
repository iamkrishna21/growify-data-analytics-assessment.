# Growify Data Analytics Assessment

Power BI marketing analytics project focused on campaign performance, funnel efficiency, and budget optimization for Growify Digital.

## Project Overview

This project analyzes marketing and e-commerce data to identify performance trends, evaluate campaign efficiency, and develop data-driven recommendations for improving marketing ROI and sales growth.

The analysis combines Python-based data preparation with Power BI dashboards and business analysis.

## Objectives

- Analyze marketing campaign performance across platforms and campaigns
- Evaluate spending, revenue, purchases, ROAS, CTR, and conversion performance
- Identify funnel efficiency and areas of improvement
- Compare planned targets with actual performance
- Identify opportunities for budget reallocation
- Develop recommendations to support a 25% sales growth strategy

## Tools & Technologies

- **Python** — Data cleaning, validation, transformation, and analysis
- **Pandas** — Data processing and preparation
- **Power BI** — Interactive dashboards and business intelligence
- **DAX** — Measures and analytical calculations
- **CSV** — Data storage and exchange
